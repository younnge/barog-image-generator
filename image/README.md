# 원내이미지 생성기 (barog-image-generator)

원내 이벤트 전단지용 **A4 이미지 생성기**. 빌드/백엔드 없는 **클라이언트 전용 정적 웹앱**으로,
브라우저 canvas에서 A4(1240×1754, 2배 스케일) 이미지를 만들고 JPEG로 내려받습니다.

사내 마케팅팀 전용 도구입니다. 입력한 내용은 브라우저를 벗어나지 않습니다
(외부로 데이터를 보내는 코드가 없습니다).

## 실행

정적 파일이라 서버에 올리거나 로컬에서 정적 서버로 열기만 하면 됩니다.

```bash
# 로컬 미리보기 (둘 중 아무거나)
python -m http.server 8000      # → http://localhost:8000
npx serve .
```

> `file://` 직접 열기는 CSP/폰트 로딩 때문에 권장하지 않습니다. 반드시 http로 서빙하세요.

**권장 브라우저: Chrome 또는 Edge.** 캔버스 자간(`ctx.letterSpacing`)은 Firefox 129+ 부터
지원되며, 미지원 브라우저에서는 오류 없이 자간만 어긋난 채 출력됩니다.

## 테스트

```bash
npm test                       # 전체 (tests/run.js)
node tests/lang.test.js        # 파일 하나만 실행해도 됩니다
```

| 파일 | 무엇을 지키는가 |
|---|---|
| `tests/logic.test.js` | DSL 파서·가격 토큰화·높이 분할·금지어 감지 |
| `tests/lang.test.js` | 문서 언어 자동 판별, 간체/번체 글자표 건전성, 폰트 체인 |
| `tests/render.test.js` | **측정과 그리기 높이 일치**, 가격 그리드, 로고 기하·헤더 밀림 |
| `tests/persist.test.js` | 백업·세션 복원, 세션 이미지 재기록 억제 |
| `tests/violation.test.js` | 의료법 검사 배선(제목·기간 포함), 툴팁 수명 |

`tests/helpers/` 에 공용 DOM·canvas 스텁과 러너가 있습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 마크업 + CSP/SRI + CDN(JSZip·FileSaver·폰트) |
| `main.js` | 전체 로직(입력·DSL 서식·측정/캔버스 렌더·균등 맞춤·백업) |
| `style.css` | UI 스타일 + @font-face |
| `robots.txt` | 검색 색인 차단(사내 전용) |
| `사용설명서.html` | 사용자용 도움말 — 앱 헤더의 «사용설명서» 링크로 연결 |
| `tests/` | 회귀 테스트 |

## 주요 기능

- **서식 DSL**: `<강조>`, `<+확대+>`/`<-축소->`, `{굵게}` (짝 없는 기호는 리터럴로 보존)
- **페이지 배치**: `그대로` / `높이 맞춤`(좌·우 높이 균형) / `끝까지 채움`(하단 픽셀 일치 + 간격 자동 분배)
- **상단 로고**: 이미지 업로드 후 크기(50~150%)·세로 위치(0~250px) 조절.
  넣으면 헤더가 늘어나 제목·기간이 함께 내려갑니다
- **문서 언어 자동 판별**: 입력 문구에서 한글·가나·태국문자·한자를 보고 폰트 우선순위를 정합니다.
  한자만 있으면 간체/번체 글자표(425쌍)로 구분합니다. 설정 UI는 없습니다
- **의료법 위반어 감지** + 대체어 제안 — 제목·기간·항목명·비고·가격 칸 모두 검사
- **백업/복구**: JSON 내보내기·불러오기(배경·로고·색상 팔레트 포함) + sessionStorage 자동 보존

## 배포

저장소 루트의 `.github/workflows/deploy.yml` 이 master 푸시마다 `image/` 를 GitHub Pages로 올립니다.
**`verify` job(구문 검사 + `npm test`)을 통과해야 `deploy` job이 실행됩니다.**
`test.yml` 은 pull request 검증용입니다.

## 알아두면 좋은 점

- **외부 의존**: JSZip·FileSaver(SRI 고정), 폰트(jsdelivr/Google, `font-display:swap`).
  폐쇄망에서는 저장/ZIP이 막히고 폰트가 대체될 수 있습니다(앱이 토스트로 안내).
- **폰트 고정**: Paperlogy는 커밋 해시로 고정돼 있습니다. 브랜치(`@main`)를 쓰면
  상류 변경 시 인쇄물 글자 모양이 예고 없이 달라집니다.
- **큰 배경 이미지**: 약 3.7MB를 넘으면 sessionStorage 한도를 넘어 새로고침 시 사라집니다.
  앱이 안내하며, 저장(백업) 기능을 쓰면 유지됩니다.
- **공개 접근**: 공개 저장소의 GitHub Pages는 접근 제한을 걸 수 없습니다.
  `robots.txt` + `noindex` 로 검색 노출만 막아 둔 상태이며, URL을 아는 접근은 가능합니다.
